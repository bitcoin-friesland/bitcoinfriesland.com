# Sats calculator

The sats calculator converts sats to euros or dollars and back, with the live bitcoin price from mempool.space (CoinGecko as backup). The page also shows a table of common amounts (1, 50, 100, 1,000, 10,000, 21,000, 100,000 and 1,000,000 sats) in euros and dollars.

## Fixed facts

- 1 bitcoin = 100,000,000 sats. 1 sat = 0.00000001 BTC.
- 1,000 sats = 0.00001 BTC. 21,000 sats = 0.00021 BTC. 100,000 sats = 0.001 BTC. 1,000,000 sats = 0.01 BTC.
- Sats and bitcoin are the same money in a different unit, like cents and euros.
- The value in euros or dollars changes with the price. Use the calculator for the current amount; this summary deliberately states no price.

The result is an indication and not financial advice.
